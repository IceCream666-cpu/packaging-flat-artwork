# 包装效果图转平面展开稿

适用于 Codex 的技能：先读取包装效果图与现有资料，再针对具体产品分轮问答，补齐尺寸、装填、结构、材料和工艺信息，制作可编辑的平面展开设计。

## 安装

将本仓库完整复制到 `~/.codex/skills/packaging-flat-artwork`。已存在同名技能时先比较版本，保留本地修改。仓库为私有时，需要有访问权限。

新安装后，在新对话中使用；若技能列表没有刷新，重启客户端后再调用。

## 调用示例

```text
使用 $packaging-flat-artwork，先读取我的产品效果图和已有资料，
针对缺少的长宽高、装填、材料和工艺进行分轮Q&A，
答案明确后制作对应的平面展开稿，并记录工厂与打样待确认项。
```

## 问答与交付

- 每轮询问1–3项关键缺项，已提供的信息不重复询问。
- 按卫生巾纸盒、瓶罐外盒、礼盒或软袋等实际产品选择问题。
- 记录尺寸单位、内外尺寸、来源、SKU，以及用户/工厂确认或待确认状态。
- 关键答案未到齐时只推进不依赖这些答案的工作，不猜测生产参数。
- 输出按任务需要包括可编辑源稿、展开预览、审阅PDF、工艺版和参数确认表。
