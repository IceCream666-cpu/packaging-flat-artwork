# 效果图确认后的实物落地参数

效果图确定视觉；能制造的展开文件还需要结构依据、尺寸依据、材料、印刷素材及工艺数据。用户提供用途/产品/视觉与内容，包装厂通常提供刀模、纸材和设备允许值，设计方负责套版、分版和核对。工厂未确定的参数不得默认为确认值。

## A. 做出能装产品、能折合的纸样：结构必需

| 参数 | 至少要明确什么 | 通常来源 | 缺失时能做什么 |
| --- | --- | --- | --- |
| 实际装入物 | 产品或独立小包的长宽厚、数量、堆叠方向、压缩状态；最好有实物样品 | 用户/产品工厂 | 只能检查外观，不能保证装得下 |
| 成品尺寸 | W×D×H、对应正面方向，内尺寸或外尺寸，允许公差；cm/mm统一 | 用户确认+包装厂核对 | 做比例稿，不能称实际比例结构 |
| 盒型与开启方式 | 插口/锁底/糊底/天地盖等，开口位置、撕条、挂孔、窗口、是否需内托 | 用户+包装厂 | 选明确标注的参考结构，不能当最终刀模 |
| 工厂结构刀模 | 1:1实际单位；裁切、压痕、插舌、折耳、粘口/糊盒区、撕线、装配方向；文件版本与批准状态 | 包装厂/结构工程师 | 可制作设计参考展开，不能保证折合与设备适配 |
| 基材 | 纸/纸板/膜材类型、克重与实际厚度、表面涂布/复膜、纸纹方向（适用时） | 包装厂 | 无法准确确定厚度补偿、折叠和承载表现 |
| 组装与装填 | 机器或手工糊盒、封装方式、装填方向及内托要求；关键工序余量由工厂给定 | 包装厂/装填方 | 不承诺能直接进入指定产线 |

只给“350 g白卡”还不足以推导实际厚度；只给外尺寸也不能据此保证内部容量。柔性卫生巾小包应按实际堆叠/压缩状态试装，不能简单把单片标称厚度相加。

## B. 做出与定稿相符的印刷图稿：内容与印前必需

| 参数/素材 | 要求 | 通常来源 |
| --- | --- | --- |
| 最终版本和SKU表 | 每款品名、规格、数量、尺寸、对应视觉；冲突列表先解决 | 用户/品牌方 |
| Logo/字体 | 原始矢量Logo；字体或已转曲稿；可编辑源与转曲交付副本分开 | 品牌/设计方 |
| 图片/背景 | 原始高分辨率或可编辑素材；清晰区分允许重建的背景与必须保留的图案 | 品牌/设计方 |
| 全部版面文案 | 正面、背面、侧面、顶底定稿；产品信息由用户或实际生产方核准 | 品牌/生产方 |
| 条码/二维码 | 正确数据或原始图稿、实际印刷尺寸、静区、扫码内容；可变数据区域及打码方式 | 品牌/生产方 |
| 印刷与色彩 | 印刷方式、基材颜色、四色/专色、目标色样或色号、印厂色彩配置与输出要求 | 印厂+用户确认色样 |
| 出血与安全区 | 实际刀模对应的出血、避让裁切/压线/糊口的安全距离、最小文字/线宽 | 印厂 |
| 文件交接 | 印厂接收格式、实际比例、字体、链接图片、图层与专色命名、是否需要指定PDF规范 | 印厂 |

例如“浅蓝色”只能表达设计意向；最终实物颜色需目标色值/色样与打样比较。不能把屏幕RGB预览当成纸张上的颜色承诺。印厂尚未给出时，3 mm出血、300 ppi等只能作为可讨论的设计参考，不能称该订单的已确认标准。

## C. 做出效果图里的材质感：有该工艺才需补充

| 工艺 | 必须补充的数据 |
| --- | --- |
| 局部UV | 明确施加在哪些图形；独立同坐标蒙版；平UV或凸UV、亮/哑效果；最小线宽/间隙、套准余量由工厂确认 |
| 全面上光/覆膜 | 覆盖范围、亮/哑类型、与纸材/后道工艺的兼容条件 |
| 烫金/烫银 | 箔材型号或色样、独立版、范围、避让和套准要求 |
| 压凸/击凹 | 独立版、位置、目标凹凸方向和效果，深度及模具细节由工厂确认 |
| 开窗/透明件 | 实际裁切轮廓、窗口材料与厚度、粘贴边、与主体结构的关系 |

“做UV亮面”不足以确定施加范围。高光照片不能替代工艺版。需要实物浮雕或凸起云朵时，平面印刷阴影加普通上光不等于实际凸起。

## D. 文件与实物分别验证

1. 结构核对或白样：按实际纸材折盒、试装，检查开合、容量、粘口、撕条和组装方向。
2. 印刷/工艺样：核对纸材、颜色、图文清晰度、扫码、UV/烫印套准及折线外观。
3. 用户/工厂确认最终版本和允许偏差后再按该版本量产。样品测试未完成应如实说明，不能以PDF导出成功代替。

工厂可以通过其他已验证结构和生产流程承担上述验证；设计方记录实际证据，不强迫每单重复无必要的流程。

## 本次花莳里资料能证明什么

已有：用户确认的5页视觉展开稿、标题标注的5款盒尺寸、各面大部分文案和结构线示意。

仍需核实：正式刀模实际比例与版本、红色线的类型/分版状态、内外尺寸口径、纸材厚度、实际装填状态、码位数据、原始Logo/图像可提取性、印刷色彩要求、UV施加范围和独立工艺版、工厂打样状态。优先从现有PDF/原AI源文件检查，不能未经检查就断言素材不存在。

本例的“设计最终定稿”是用户已确认视觉版本，不自动等于全部生产参数和印前检查已确认。
